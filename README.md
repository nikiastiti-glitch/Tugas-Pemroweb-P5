1. HTML (index.html)
HTML digunakan untuk membuat struktur halaman web, seperti:
- <h2>    untuk menampilkan judul.
- <input> untuk memasukkan nilai mahasiswa.
- <button> untuk menjalankan program.
- <p> untuk menampilkan hasil nilai dan perulangan.
- <script> untuk menghubungkan file JavaScript.
2. CSS (style.css)
CSS digunakan untuk mengatur tampilan halaman, seperti jenis huruf, warna latar belakang, warna judul, ukuran input, dan tombol agar terlihat lebih rapi.
3. JavaScript (script.js)
JavaScript digunakan untuk menjalankan logika program.
- function hitung(): menjalankan program ketika tombol diklik.
- let nilai: menyimpan nilai yang dimasukkan pengguna.
- if, else if, else: menentukan grade berdasarkan nilai mahasiswa. Terdapat lima kondisi, yaitu grade A, B, C, D, dan E.
- for: mengulang tulisan Belajar sebanyak tiga kali.
- while: mengulang tulisan Latihan sebanyak dua kali.
- innerHTML: menampilkan hasil grade dan perulangan pada halaman web.
Kesimpulan
Program ini menggabungkan HTML untuk struktur, CSS untuk tampilan, dan JavaScript untuk proses. Percabangan digunakan untuk menentukan grade mahasiswa, sedangkan perulangan digunakan untuk menampilkan tulisan secara berulang.
